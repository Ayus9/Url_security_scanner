Step 1 — Open Project Folder
                Go inside your project:
                                    cd "C:\VS CODE\Url Project\url-scanner"


Step 2 — Create .env File
                    In VS Code:
                                Right Click → New File

                                             Name it exactly:  ".env"


Step 3 — Add Keys
            Paste inside .env:

                           " VT_API_KEY=your_virustotal_key

                            ZAP_API_KEY=your_zap_api_key
                            ZAP_PROXY=http://127.0.0.1:8080 "


Step 4 — Install dotenv
                     Open terminal:
                                " pip install python-dotenv "



Step 5 — Load .env in Python
                        
        At top of app.py:

              "  from dotenv import load_dotenv
                import os

                load_dotenv() "


Step 6 — Access Variables
                    
                    VT_API_KEY = os.getenv("VT_API_KEY")

                    ZAP_API_KEY = os.getenv("ZAP_API_KEY")
                    ZAP_PROXY = os.getenv("ZAP_PROXY")



Step 7 — Add .env to .gitignore

                 Create/edit .gitignore:

                        .env

 This keeps API keys private when uploading to GitHub
.


Final ::

            Now every time you run:

           " python app.py "

your VirusTotal + ZAP keys load automatically ✅
